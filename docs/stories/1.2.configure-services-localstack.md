## Usage Examples

### Publishing to SNS Topic
```typescript
import { getSnsClient, publishToTopic, getTopicArn } from '@uit-go/common-utils/aws';

const topicArn = getTopicArn('trip-matching-events');
await publishToTopic(topicArn, {
  tripId: '123',
  passengerId: '456',
  status: 'requested',
});
```

### Receiving from SQS Queue
```typescript
import { getSqsClient, receiveMessages, getQueueUrl } from '@uit-go/common-utils/aws';

const queueUrl = getQueueUrl('trip-matching-queue');
const messages = await receiveMessages(queueUrl, 10);

for (const message of messages) {
  const data = JSON.parse(message.Body);
  console.log('Received:', data);
  await deleteMessage(queueUrl, message.ReceiptHandle);
}
```

## Technical Notes

### LocalStack Account ID
LocalStack uses `000000000000` as the default AWS account ID in ARNs:
```
arn:aws:sns:us-east-1:000000000000:topic-name
```

### Environment Variable Priority
1. `AWS_ENDPOINT_URL` → If set, use LocalStack
2. No endpoint → Use real AWS (IAM role credentials)

### Services Need Rebuild
After modifying `docker-compose.yml`, services must be restarted:
```bash
docker-compose -f docker-compose.yml -f docker-compose.localstack.yml up -d --build
```
