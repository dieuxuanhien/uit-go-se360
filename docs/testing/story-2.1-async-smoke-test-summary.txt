  Stage 3: Peak      (60s)  │ 30 ━━━━━━━ 30 VUs │ Sustained peak (30 concurrent)
  Stage 4: Ramp-down (30s)  │ 30 ◄─────── 0 VUs  │ Gradual shutdown
  
  ┌─ Per-Iteration Flow (Fire-and-Forget Pattern) ──────┐
  │ 1. Each VU uses unique user (VU1→User1, VU2→User2)  │
  │ 2. POST /users/login → get JWT token (reused)       │
  │ 3. Select random HCM pickup/dropoff locations        │
  │ 4. POST /trips (with Authorization header)           │
  │    ├─ Trip created in DB (REQUESTED status)         │
  │    ├─ SNS publish to trip-events topic              │
  │    └─ Immediate HTTP 201 response (no blocking)     │
  │ 5. Validate: HTTP 201, trip.id, status=REQUESTED    │
  │ 6. Sleep 1-2s (think time)                          │
  │ 7. Repeat                                            │
  └──────────────────────────────────────────────────────┘
  
  Total iterations: 2,245 complete
  Iteration rate: 12.46 iterations/s
  VU distribution: Each VU cycled through unique user (30 users, 30 VUs)
